# Checklist QA — modo tablet

Probar en **modo claro y oscuro** en cada viewport.

| Viewport | Dispositivo referencia |
|----------|------------------------|
| 390×844 | iPhone |
| 768×1024 | iPad portrait |
| 834×1194 | iPad Air portrait |
| 1024×768 | iPad landscape |
| 1180×820 | iPad landscape ancho |
| 1280×800 | Desktop pequeño |
| 1440×900 | Desktop estándar |

## Criterios globales

- [ ] Sin scroll horizontal de **página** (solo tablas/planillas con scroll contenido)
- [ ] Menú: drawer T1, rail iconos T2, sidebar completa T3–T4
- [ ] Botones no 100% ancho en tablet salvo CTAs críticos en móvil
